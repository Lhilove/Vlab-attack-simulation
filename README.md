# 🧪 Virtual Lab Simulation: ARP Spoofing (Man-in-the-Middle Attack)

This project demonstrates a basic ARP spoofing attack in a controlled virtual lab environment using Kali Linux and a victim machine (e.g., Ubuntu/Cisco Linux). It sets up a man-in-the-middle (MITM) attack to intercept network traffic between a target machine and the gateway.


## 🔧 Lab Setup

### 🖥️ Virtual Machines Used:
- **Attacker**: Kali Linux (2025.1)
- **Victim**: Ubuntu/Cisco VM
- **Virtualization Tool**: Oracle VirtualBox
